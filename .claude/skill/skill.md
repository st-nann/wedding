# Wedding Seating Site

เว็บ static ไฟล์เดียว (`index.html` = HTML + CSS + JS ล้วน ไม่มี build step, ไม่มี dependency นอกจาก Google Fonts) หลายหน้าด้วย hash routing ภาษาไทย ใช้งานบนมือถือเป็นหลัก

## ฟีเจอร์ปัจจุบัน
- หน้าแรก: ช่องค้นหาพร้อม dropdown แนะนำชื่อ, ปุ่มฝ่ายเจ้าบ่าว/เจ้าสาว (ภาพวาด SVG), ลิงก์ "ดูทุกโต๊ะ"
- ฝ่าย → หมวด (ญาติ/เพื่อน/คนที่ทำงาน) → กลุ่มย่อย → รายชื่อแยกตามโต๊ะ (กลุ่มที่คนเยอะแสดงหลายโต๊ะ) พร้อม breadcrumb
- หน้าผลลัพธ์: การ์ดต้อนรับ เลขโต๊ะตัวใหญ่ แผนผัง+เส้นทาง ที่นั่งของผู้ใช้ และรายชื่อคนร่วมโต๊ะ, ปุ่ม "ไม่ใช่ฉัน ค้นหาใหม่"
- Effect: โต๊ะเด้งทีละโต๊ะ, วงแหวน/จุดแดงเต้นที่โต๊ะและที่นั่ง, เส้นทางจุดไข่ปลาวิ่ง, เลขโต๊ะนับขึ้น+แสงวาบ+ประกาย, ดอกไม้เล็กๆ ร่วงทั้งหน้า (ปิดอัตโนมัติเมื่อผู้ใช้ตั้ง reduced motion)
- ธีมสว่างอย่างเดียว (ไม่มี dark mode): ชมพู `rgb(255,203,196)`, เหลือง `rgb(255,249,196)`, ฟ้า `rgb(191,213,244)`, น้ำเงินตัวอักษร `rgb(51,41,112)`

## โครงสร้างข้อมูล (ในแท็ก `<script>` ของ index.html)
| ตัวแปร | หน้าที่ |
|---|---|
| `TITLE` | ข้อความ hashtag/alt ของงาน |
| `TITLE_IMG`, `DECOR_IMG` | รูปหัวเว็บ 2 รูป (data URI ของ WebP/PNG โปร่งใส หรือ URL ถ้าโฮสต์เอง) ถ้า `TITLE_IMG` ว่างจะแสดง `#TITLE` เป็นข้อความ |
| `STRUCT` | หมวดและกลุ่มย่อย `[['ญาติ',['ญาติฝ่ายพ่อ','ญาติฝ่ายแม่']], ['เพื่อน',[...]], ['คนที่ทำงาน',[...]]]` ลำดับในอาเรย์ = เลข index ที่ `RAW` อ้างถึง |
| `RAW` | หนึ่งแถวต่อหนึ่งโต๊ะ: `[เลขโต๊ะ, 'G'หรือ'B', เลขหมวด, เลขกลุ่มย่อย, 'ชื่อ1,ชื่อ2,...']` |
| `SEATS` | จำนวนที่นั่งต่อโต๊ะ (ค่าเริ่มต้น 10) |
| `COLS` | จำนวนคอลัมน์โต๊ะในแผนผัง (ค่าเริ่มต้น 3) |
| `gen()`, `FN` | ตัวสร้างชื่อตัวอย่าง **ต้องลบทิ้งเมื่อใส่รายชื่อจริง** (รวมแถวใน `RAW` ที่เรียก `gen(...)`) |

กติกาของ `RAW`
- `G` = ฝ่ายเจ้าบ่าว, `B` = ฝ่ายเจ้าสาว
- ลำดับชื่อ = ลำดับที่นั่งรอบโต๊ะ ตามเข็มนาฬิกาเริ่มจากบนสุด
- โต๊ะละไม่เกิน `SEATS` คน, เลขโต๊ะห้ามซ้ำ, 1 โต๊ะมีฝ่าย/หมวด/กลุ่มย่อยเดียว (ใช้เป็นป้ายกลุ่มของโต๊ะ)
- กลุ่มที่คนมากให้แยกเป็นหลายแถวที่มีฝ่าย/หมวด/กลุ่มเหมือนกัน
- ชื่อในโค้ดจะมีคำนำหน้า "คุณ" เติมให้อัตโนมัติ ใส่เฉพาะชื่อ-นามสกุล

## งานที่ทำบ่อย
1. **ใส่รายชื่อจริง** รับ CSV/Excel คอลัมน์ `ชื่อ,โต๊ะ,ฝ่าย,หมวด,กลุ่มย่อย` แล้วแปลงเป็นแถว `RAW`:
   ```python
   import csv, collections, json
   STRUCT = [['ญาติ',['ญาติฝ่ายพ่อ','ญาติฝ่ายแม่']],['เพื่อน',['เพื่อนประถม','เพื่อนมัธยม','เพื่อนมหาลัย']],['คนที่ทำงาน',['ทำงานที่ A','ทำงานที่ B','ทำงานที่ C']]]  # ให้ตรงกับในไฟล์
   side = {'เจ้าบ่าว':'G','เจ้าสาว':'B'}
   tables = collections.OrderedDict()
   for r in csv.DictReader(open('guests.csv', encoding='utf-8-sig')):
       c = [x[0] for x in STRUCT].index(r['หมวด']); u = STRUCT[c][1].index(r['กลุ่มย่อย'])
       t = tables.setdefault(int(r['โต๊ะ']), [side[r['ฝ่าย']], c, u, []])
       t[3].append(r['ชื่อ'].strip())
   for n, (s, c, u, names) in tables.items():
       assert len(names) <= 10, f'โต๊ะ {n} เกิน 10 คน'
       print(f"[{n},'{s}',{c},{u},{json.dumps(','.join(names), ensure_ascii=False)}],")
   ```
   จากนั้นลบ `gen`/`FN`/แถวตัวอย่างเดิม แล้ววางแถวใหม่ใน `RAW` ตรวจว่าไม่มีชื่อซ้ำและทุกค่า index มีอยู่ใน `STRUCT`
2. **เพิ่มกลุ่มย่อย/หมวด** เพิ่มท้ายอาเรย์ใน `STRUCT` เท่านั้น (อย่าแทรกกลาง เพราะ index เดิมจะเลื่อน)
3. **เปลี่ยนรูปหัวเว็บ** ต้องใช้ไฟล์ที่โปร่งใสจริง (ระวังอย่าแปลงเป็น RGB ซึ่งทำให้พื้นโปร่งใสกลายเป็นสีดำ) แปลงด้วย Pillow เป็น WebP ความกว้างไม่เกิน ~760px แล้วใส่เป็น `data:image/webp;base64,...` รูปที่พื้นขาวติดกับชุดขาว (เช่นภาพเจ้าสาว) ให้ใช้เครื่องมือตัดพื้นหลัง (เช่น `rembg`)
4. **เปลี่ยนสี** แก้ตัวแปร CSS ใน `:root` (`--tx`, `--gs`, `--bs`, `--g`, `--b`, `--gold`, `--golds`, `--zone`, `--bgimg`) พื้นแผนผังคือ `--zone` (ขาว)
5. **ปรับ effect** ดอกไม้ร่วง: จำนวนดอกอยู่ที่ลูป `for(let i=0;i<18;i++)` ในสคริปต์, ความเร็วที่ `animation-duration` และ keyframes `fall`; ชื่อ keyframes อื่นๆ ได้แก่ `pop`, `fadeup`, `march`, `ring`, `beat`, `shine`, `tw`
6. **ผังตามห้องจริง** ปัจจุบันจัดกริดอัตโนมัติ ถ้าต้องการตำแหน่งจริง ให้แก้ฟังก์ชัน `pos(t)` และ `mapSvg`

## ข้อควรระวัง
- รูปแบบ hash ต้องคงเดิม: `#home`, `#side-G`, `#cat-G-0`, `#sub-G-0-1`, `#tables`, `#guest-<id>`, `#table-<n>`
- `guest-<id>` คือลำดับแขกตามการอ่าน `RAW` ถ้าจัดลำดับใหม่ ลิงก์ `#guest-` ที่เคยแชร์จะชี้ผิดคน
- ไม่ใช้ `localStorage` หรือ API ภายนอก ข้อมูลทั้งหมดอยู่ในไฟล์เดียว
- ถ้าโฮสต์ใน Claude artifact ต้องฝังรูปเป็น data URI เท่านั้น (บล็อกรูปจากเว็บอื่น); บน GitHub Pages ใช้ URL ได้
- ใช้ `’` และเครื่องหมายคำพูดแบบสวยในข้อความที่ผู้ใช้เห็น คง `'`/`"` ตรงไว้ในโค้ด
- รายชื่อแขกเปิดสาธารณะทั้งหมดเมื่อ repo เป็น public แจ้งผู้ใช้ทุกครั้งที่ใส่รายชื่อจริง

## ทดสอบก่อนอัปโหลด
เปิด `index.html` ในเบราว์เซอร์ แล้วเช็ก: ค้นหาชื่อ (dropdown, กด Enter), ฝ่าย→หมวด→กลุ่มย่อย→ผลลัพธ์, breadcrumb กดกลับได้, "ดูทุกโต๊ะ", ปุ่ม "ไม่ใช่ฉัน ค้นหาใหม่", โต๊ะที่มีหลายโต๊ะในกลุ่มเดียว, หน้าจอมือถือ และเปิดสลับโหมดมืดแล้วสียังเหมือนเดิม
