# ผังที่นั่งงานแต่งงาน 💍

เว็บ static ไฟล์เดียว (`index.html`) ให้แขกค้นหาชื่อตัวเองเพื่อดูว่านั่งโต๊ะไหน ดูแผนผังโต๊ะ เส้นทาง และรายชื่อคนร่วมโต๊ะ ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้อง build

## ไฟล์ใน repo
| ไฟล์ | คำอธิบาย |
|---|---|
| `index.html` | ตัวเว็บทั้งหมด (HTML/CSS/JS และรูปหัวเว็บฝังอยู่ในไฟล์) |
| `README.md` | ไฟล์นี้ |
| `skill.md` | คู่มือสำหรับผู้ช่วย AI/ผู้ดูแล ว่าจะแก้ข้อมูลและหน้าตาอย่างไร |

## ฟีเจอร์
- ค้นหาชื่อพร้อมรายชื่อแนะนำ (พิมพ์แค่ 2–3 ตัวอักษร)
- เลือกตามฝ่าย (เจ้าบ่าว/เจ้าสาว) → หมวด (ญาติ/เพื่อน/ที่ทำงาน) → กลุ่มย่อย
- ดูทุกโต๊ะ พร้อมชื่อกลุ่มและรายชื่อในโต๊ะ
- หน้าผลลัพธ์: เลขโต๊ะ แผนผังพร้อมเส้นทางจากทางเข้า ตำแหน่งที่นั่ง และรายชื่อคนร่วมโต๊ะ
- effect: ดอกไม้ร่วง เลขโต๊ะนับขึ้น แผนผังเคลื่อนไหว (ปิดอัตโนมัติถ้าผู้ใช้ตั้งลดการเคลื่อนไหว)

## ลองเปิดในเครื่อง
ดับเบิลคลิก `index.html` ได้เลย หรือรันเซิร์ฟเวอร์ชั่วคราว `python3 -m http.server 8000` แล้วเปิด http://localhost:8000

## ขึ้น GitHub แบบ Public และให้คนอื่นเปิดได้ (GitHub Pages)

### วิธีที่ 1: ผ่านเว็บ (ไม่ต้องใช้คำสั่ง)
1. ล็อกอิน https://github.com
2. กด **+ → New repository** ตั้งชื่อ เช่น `wedding-seating` เลือก **Public** แล้วกด **Create repository**
3. กด **uploading an existing file** ลากไฟล์ `index.html`, `README.md`, `skill.md` ลงไป แล้วกด **Commit changes**
4. ไปที่ **Settings → Pages**
5. ที่ **Build and deployment** เลือก Source = **Deploy from a branch**, Branch = **main**, โฟลเดอร์ **/ (root)** แล้วกด **Save**
6. รอ 1–2 นาที แล้วเปิด `https://<ชื่อผู้ใช้>.github.io/wedding-seating/` ลิงก์นี้ส่งให้แขกได้เลย (หรือทำเป็น QR code)

### วิธีที่ 2: ผ่าน Git
```bash
git init
git add index.html README.md skill.md
git commit -m "Wedding seating site"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/wedding-seating.git
git push -u origin main
```
แล้วทำขั้นตอนที่ 4–6 ด้านบน

### วิธีที่ 3: GitHub CLI
```bash
gh repo create wedding-seating --public --source=. --push
gh api -X POST repos/<ชื่อผู้ใช้>/wedding-seating/pages -f "source[branch]=main" -f "source[path]=/"
```

## อัปเดตรายชื่อ
1. เปิด `index.html` หาค่า `RAW` (ใกล้ต้นแท็ก `<script>`) แล้วแก้ เช่น `[6,'B',0,0,'สมพร รักษ์ไทย,สมใจ รักษ์ไทย,...]` หมายถึง โต๊ะ 6 ฝ่ายเจ้าสาว หมวดญาติ กลุ่มญาติฝ่ายพ่อ
2. ลบข้อมูลตัวอย่าง (`gen(...)` และ `FN`) ออกก่อนใช้งานจริง
3. Commit ใหม่ เว็บจะอัปเดตเองภายในไม่กี่นาที (ถ้ายังเห็นของเก่า ให้รีเฟรชแรงๆ)

รูปแบบข้อมูลและวิธีแปลงจาก CSV อยู่ใน `skill.md`

## ปรับแต่งอย่างรวดเร็ว
| ต้องการ | แก้ที่ |
|---|---|
| ชื่องาน | `TITLE` |
| รูปหัวเว็บ | `TITLE_IMG`, `DECOR_IMG` (data URI หรือ URL) |
| หมวด/กลุ่มย่อย | `STRUCT` (เพิ่มท้ายอาเรย์เท่านั้น) |
| สี | ตัวแปร CSS ใน `:root` |
| จำนวนดอกไม้ร่วง | เลข `18` ในลูป `for(let i=0;i<18;i++)` |
| ที่นั่งต่อโต๊ะ / คอลัมน์ผัง | `SEATS`, `COLS` |

## เรื่องความเป็นส่วนตัว ⚠️
Repo แบบ Public และเว็บเปิดให้ทุกคนที่มีลิงก์เห็นรายชื่อแขกทั้งหมด (ผ่านหน้า "ดูทุกโต๊ะ" หรือ view source) แนะนำให้ใช้ชื่อเล่น/ชื่อต้นแทนชื่อเต็ม และไม่โพสต์ลิงก์ในที่สาธารณะ หรือใช้ repo แบบ Private ร่วมกับ GitHub Pages (ต้องใช้แพ็กเกจที่รองรับ)

## ย้ายแขกไปโต๊ะอื่น
เปิด `https://<ชื่อผู้ใช้>.github.io/wedding-seating/#edit` จะมีปุ่ม **ย้าย** หลังชื่อแขก กดแล้วกรอกเลขโต๊ะที่ต้องการใน popup การย้ายบันทึกเฉพาะในเบราว์เซอร์ของคุณ ถ้าจะให้ทุกคนเห็น ให้กด **คัดลอกรายการย้าย** ที่แถบด้านบน แล้ววางแทน `const MOVES={};` ใน `index.html` และ commit ปิดโหมดแก้ไขที่ `#exit`

> **ก่อนแชร์ให้แขก:** ตั้ง `const ALWAYS_EDIT=false;` ใน `index.html` เพื่อซ่อนปุ่ม "ย้าย" (ค่าเริ่มต้นเป็น `true` ระหว่างจัดที่นั่ง) แล้วเจ้าของยังเปิดโหมดแก้ไขได้เองที่ `#edit`
